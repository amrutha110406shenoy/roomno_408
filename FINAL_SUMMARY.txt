================================================================================
TRACKER PERFORMANCE COMPARISON
================================================================================

BoTSORT (Appearance-based tracking):
  Pros:
    ✓ Better accuracy on difficult targets
    ✓ More stable tracking in complex scenes
    ✓ Lower ID switch rate
    ✓ Better for dense object scenarios

  Cons:
    ✗ 25-35% slower than ByteTrack
    ✗ Higher computational cost
    ✗ Not ideal for real-time on CPU

  Best for: Archive/accuracy-critical systems

ByteTrack (Lightweight association):
  Pros:
    ✓ 25% faster than BoTSORT
    ✓ Real-time capable on CPU
    ✓ Lower computational overhead
    ✓ Smooth tracking for most scenes

  Cons:
    ✗ Slightly more ID switches in complex scenarios
    ✗ Less stable in dense scenes

  Best for: Real-time systems, edge devices
